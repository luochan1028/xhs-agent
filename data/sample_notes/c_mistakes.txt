C语言新手最常错的3个点！别再踩了
新手写 C 语言，这 3 个错几乎人人踩过，改掉就顺了。😅
❌ 错误 1：把 main 写成 void main()——应为 int main(void)，返回 0。
❌ 错误 2：scanf("%d", n) 漏了 &——应为 scanf("%d", &n)，不加 & 读不到数。
❌ 错误 3：if (x = 1) 写成了赋值——比较要用 if (x == 1)，一个等号是赋值、两个才是比较。
改的方法也简单：main 只写 int main(void)；scanf 读数永远记得 &；比较永远用 ==，赋值才用 =。这三条背下来，代码少一半 bug。
三个实验里都有现成的正确写法：实验一 hello.c、实验二 grade_stats.c、实验三 student_manager.c，对着抄一遍就记住了。
这三个都是编译器不一定报错、但运行结果会错的坑。写完先用 gcc -Wall 编译，有警告先修警告。💻
