成绩统计45行代码！循环判断一次练会
实验二：成绩统计，45 行代码练会循环+判断。输入 5 个成绩，输出平均分 82.20、最高分 92、最低分 66。📊
核心就三段：先读人数并校验（人数须为正整数，否则提示并返回 1）；再用 for 循环逐个读成绩，0 到 100 之外就提示重输；边读边累加、边更新最高分和最低分。
最小核心代码：
```c
for (i = 0; i < n; i++) {
    scanf("%d", &score);
    sum += score;
    if (score > max) max = score;
    if (score < min) min = score;
}
```
注意 scanf 一定要加 &，漏了就是错。if 里面是比较，写成 = 就变赋值了。
