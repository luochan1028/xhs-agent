指针3天搞懂！画图法一次讲清
姐妹们，指针是不是你学 C 语言的头一道坎？我当年也是，看到 * 和 & 就晕。😅
其实指针就一句话：指针就是一个装地址的变量。int *p = &a 的意思是：p 里装的是变量 a 的地址。想改 a 的值，不用碰 a，直接 *p = 10 就行。
画图法最管用：画两个格子，一个是 a（值 5），一个是 p（值是 a 的地址），箭头从 p 指向 a。*p 就是顺着箭头找到 a。📝
最小代码（能编译）：
```c
#include <stdio.h>
int main(void) {
    int a = 5;
    int *p = &a;
    *p = 10;
    printf("%d\n", a);
    return 0;
}
```
输出是 10。记住三句话：& 是取地址，* 是顺着地址取值，指针本身也是变量。你们学指针卡在哪一步？评论区聊聊 👇
